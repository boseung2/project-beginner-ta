3. Step1

  • 비밀번호 확인 입력창

  • "회원가입" 버튼 추가
  • 버튼을 눌렀을 때 입력한 값이 alert로 출력되면 성공

4. Step2

🎯 Step 2에서 추가되는 기능

✔️ 1. 비밀번호 & 비밀번호 확인 비교

  • password 와 passwordConfirm이 같은지 실시간 확인
  • 조건에 따라 아래 문구를 화면에 표시:
    • 초록색: "비밀번호가 일치합니다."
    • 빨간색: "비밀번호가 일치하지 않습니다."

✔️ 2. 조건부 렌더링(Conditional Rendering)

  • 비밀번호 확인 입력칸에 값이 있을 때만 문구 표시
  • 상태에 따라 style(color)을 다르게 적용

5. Step3

🎯 Step 3에서 추가되는 기능

✔️ 1. 닉네임 기반 자동 추천 닉네임

  • 닉네임을 입력하면 그 값을 이용해 아래처럼 추천 닉네임을 생성
  • 예: nickname = "user" → 추천 닉네임: user_123
  • 1초 후 nickname 추천
  • 닉네임이 비어 있으면 추천 문구 숨김

✔️ 2. useEffect로 "닉네임 변경 → 추천 변경" 연결하기

  • Step3에서는 useEffect를 사용해
    "nickname 값이 바뀌면 suggestion 업데이트" 라는 흐름을 직접 연습

6. Step4

📝 Step 4 완성 체크 리스트

  • 이메일 형식이 틀리면 "이메일 형식이 올바르지 않습니다." (빨간색) 표시
  • 이메일 형식이 맞으면 "이메일 형식이 올바릅니다." (초록색) 표시
  • 닉네임 입력 시 추천 닉네임이 3개 생성된다
  • 추천 닉네임이 한 줄에 "추천 닉네임: a b c" 형태로 표시된다
  • Step3까지의 비밀번호 검증, 회원가입 alert 동작도 그대로 유지된다
