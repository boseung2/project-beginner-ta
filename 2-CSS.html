1. 선택자

CSS 규칙은 선택자로 대상을 고르고, 속성: 값으로 모양을 정합니다.

선택자 { 속성: 값; }      예)  p { color: red; }

예제는 <head> 안의 <style>에 CSS를 작성합니다.

1-1. 선택자의 종류

자주 쓰는 선택자는 일곱 가지입니다. 이것만 알아도 대부분의 화면을 꾸밀 수 있어요.

  • 전체 * — 모든 요소
  • 태그 p — 그 태그 전부
  • 클래스 .highlight — class 속성이 같은 요소들. 여러 곳에 재사용
  • ID #intro — id 속성이 같은 요소 하나. 문서에 하나만
  • 그룹 h1, h2 — 여러 선택자에 같은 스타일
  • 후손 .hobbies li — 안쪽 어디에 있든
  • 자식 .card > p — 바로 아래 한 단계만

1-2. 상속과 우선순위

상속: 글자색·글꼴·줄간격처럼 텍스트에 관한 속성은 부모에서 자식으로 내려갑니다. 여백·테두리·크기는 내려가지 않습니다.

우선순위: 한 요소에 여러 규칙이 겹치면 더 구체적인 선택자가 이깁니다. 점수는 (ID, 클래스, 태그) 세 자리로 셉니다.

1순위style="…"인라인 스타일. 선택자보다 항상 강함
2순위#idID 선택자 → 1-0-0
3순위.class [attr] :hover클래스 · 속성 · 의사클래스 → 0-1-0
4순위p ::before태그 · 의사요소 → 0-0-1
같으면나중에 쓴 규칙점수가 같을 때는 아래쪽에 작성한 규칙이 적용
예외!important모든 것을 덮어씀. 디버깅이 어려워지니 최후 수단

여러 개가 합쳐지면 자리별로 더합니다. .box p는 0-1-1, #box.box p는 1-1-1이라 뒤쪽이 이깁니다.

개발자 도구 → 요소(Elements) → 스타일(Styles)에서 적용된 규칙과 취소선이 그어진 규칙을 확인해 보세요.

1-3. 선택자 정리표

필요할 때 찾아보는 참고용입니다. 위의 일곱 가지 외에 속성·형제·상태·가상 요소 선택자가 있습니다.

전체 선택자*모든 요소를 선택
타입 선택자E태그명(E)으로 선택
클래스 선택자.classclass 속성값으로 선택
ID 선택자#idid 속성값으로 선택(문서 내 고유 권장)
속성 선택자[attr]속성이 존재하는 요소 선택
속성 선택자[attr=value]속성 값이 일치하는 요소 선택
속성 선택자[attr^=v] [attr$=v] [attr*=v]접두 / 접미 / 포함 일치
후손 결합자E FE 내부의 모든 F를 선택
자식 결합자E > FE의 직계 자식 F를 선택
인접 형제E + FE 바로 뒤의 형제 F를 선택
일반 형제E ~ FE 뒤의 모든 형제 F를 선택
의사클래스:hover, :focus상호작용/상태에 따라 선택
의사클래스:active, :visited활성 / 방문 상태
의사클래스:first-child / :last-child부모의 첫 / 마지막 자식
의사클래스:nth-child(n)n번째 자식(수식 사용 가능)
의사클래스:nth-of-type(n)동일 태그 타입 기준 n번째
부정 선택:not(sel)sel에 해당하지 않는 요소
의사요소::before / ::after가상 요소 생성(콘텐츠 삽입)
의사요소::first-line / ::first-letter첫 줄 / 첫 글자에 스타일
고급:is() / :where()여러 선택자 그룹을 축약; :where는 특이성 0
관계:has()자식/후손 조건을 가진 요소 선택(브라우저 지원 확인)

1-4. 텍스트 스타일 정리표

글자에 관한 속성 모음입니다. 위 6개(color ~ line-height)가 가장 자주 쓰입니다.

color글자 색상
font-family글꼴 패밀리(대체 목록 권장)
font-size글자 크기(px, em, rem 등)
font-weight굵기(100–900, normal/bold)
font-style기울임(italic) 등
line-height줄 간격(단위 없이 배수 권장)
letter-spacing자간
word-spacing어간
text-align좌 / 우 / 가운데 / 양쪽 정렬
text-decoration밑줄 / 취소선 등(색·스타일 포함 가능)
text-transform대소문자 변환
white-space공백·줄바꿈 처리 방식
text-overflow넘치는 텍스트 말줄임(ellipsis)
overflow-wrap / word-break긴 단어 줄바꿈 제어
direction / writing-mode문자 방향 / 세로쓰기 등
tab-size탭 문자의 너비
hyphens단어 하이픈 분리 제어
font-variant / font-feature-settings스몰캡, 합자 등 OpenType 기능
CSS를 별도 파일로 분리하려면?

<style> 안의 CSS를 style.css로 옮기고, HTML의 <head>에서 연결합니다.

<link rel="stylesheet" href="style.css">

HTML과 CSS 파일을 같은 폴더에 두세요.

2. 박스 모델 — margin · padding · border

내용 → 안쪽 여백(padding) → 테두리(border) → 바깥 여백(margin)

padding과 margin 값을 각각 바꿔 보세요. 개발자 도구의 박스 모델에서도 차이를 확인할 수 있습니다.

width / height너비 / 높이
max-width / min-width최대 / 최소 너비
padding테두리 안쪽 여백
margin테두리 바깥쪽 여백
border / border-radius테두리 / 모서리 둥글기
box-sizing: border-box지정한 크기에 padding과 border를 포함
overflow: auto내용이 넘칠 때 필요한 스크롤 제공

3. 박스 배치 — display와 position

3-1. display

기본 흐름에서 block은 새 줄을 만들고, inline은 글의 흐름 안에 놓입니다.

위 span에서 inline은 width가 적용되지 않고, inline-block은 적용됩니다.

3-2. position

카드 모서리의 배지처럼, 기준 위치를 정해 요소를 배치할 때 사용합니다.

static기본 문서 흐름에 배치
relative원래 자리를 유지하며 위치를 조절. 위 예제에서는 배지의 기준
absolute일반 흐름에서 빠져 기준 블록에 배치. 위 예제에서는 relative 부모 기준
fixed일반적인 경우 뷰포트 기준으로 고정. 예제에서는 실행 결과 영역 기준
sticky스크롤 영역 안에서 지정한 경계에 도달하면 달라붙음. top 등의 기준 필요
top / right / bottom / left기준으로부터의 위치
z-index겹치는 요소의 쌓임 순서. 부모의 쌓임 맥락에도 영향을 받음

4. 크기 단위와 뷰포트

px는 CSS 픽셀, %는 속성에 따른 기준값의 비율, vw·vh는 뷰포트 크기의 비율입니다.

pxCSS 픽셀 단위
%속성별 기준값에 대한 비율. 위 width 예제에서는 부모 내용 영역의 너비
rem루트(html) 글자 크기 기준
em글자 크기 기준. font-size에서 쓰면 부모의 글자 크기가 기준
vw / vh뷰포트 너비 / 높이의 1%. vh는 모바일 브라우저 UI 변화와 차이가 날 수 있음
dvh브라우저 UI 변화에 따라 달라지는 현재 뷰포트 높이의 1%

5. 미디어 쿼리

화면 너비가 600px 이하일 때 카드의 여백과 글자 크기를 바꿉니다.

위 버튼으로 실행 결과의 폭을 바꾸거나, 새 창에서 열어 브라우저 너비를 조절해 보세요.

@media (max-width: 600px)뷰포트 너비가 600px 이하일 때 적용
@media (min-width: 600px)뷰포트 너비가 600px 이상일 때 적용
max-width: 640px요소 너비의 상한. 미디어 쿼리 조건과는 다른 역할
viewport 메타 태그모바일에서 기기 너비에 맞게 페이지를 표시하도록 설정

6. 플렉스 박스

부모에 display: flex를 주면, 바로 아래 자식들을 함께 배치할 수 있습니다.

6-1. 방향과 간격

row를 column으로 바꾸고, gap도 조절해 보세요.

6-2. 정렬

row에서는 주축이 가로, 교차축이 세로입니다. column으로 바꾸면 축도 바뀝니다.

6-3. 줄바꿈

display: flex부모를 Flex 컨테이너로 설정
flex-direction주축 방향: row / column
gap자식 사이의 간격
justify-content주축 방향 정렬: flex-start / center / space-between 등
align-items교차축 방향 정렬: stretch / flex-start / center 등
flex-wrap: wrap공간이 부족하면 다음 줄로 배치
align-self자식 하나의 교차축 정렬을 따로 지정
추가로 살펴볼 속성
flex-grow남은 공간을 나눠 가지며 커지는 비율
flex-shrink공간이 부족할 때 기본 크기와 함께 축소량을 결정
flex-basis주축 방향의 기본 크기
flexgrow / shrink / basis 축약
align-content여러 줄 전체의 교차축 정렬. 해당 방향에 여유 공간이 있어야 차이가 보임

7. 트랜스폼 · 트랜지션 · 애니메이션

7-1. transform — 모양과 위치 바꾸기

버튼에 마우스를 올리거나, Tab 키로 포커스를 옮겨 보세요.

transform으로 변형해도 주변 요소의 원래 배치 공간은 그대로입니다.

7-2. transition — 변화를 부드럽게 연결하기

같은 변화를 즉시 적용할 때와 0.3초에 걸쳐 적용할 때를 비교합니다.

translate / rotate / scale이동 / 회전 / 크기 변경
transition-property전환할 속성
transition-duration전환 시간: 0.3s 등
transition-timing-function변화 속도: ease / linear 등
transition-delay전환 시작 전 대기 시간

7-3. animation — 동작 순서와 반복 정하기

@keyframes로 시작과 끝을 정하고, animation으로 시간과 반복을 지정합니다.

@keyframes시간에 따른 스타일 정의. from / to 또는 0% / 50% / 100% 등
animation-name사용할 keyframes 이름
animation-duration한 번 재생되는 시간
animation-iteration-count반복 횟수: 숫자 / infinite
animation-direction: alternate정방향과 역방향을 번갈아 재생
animation-fill-mode: forwards재생이 끝난 뒤 마지막 스타일 유지
animation-play-staterunning / paused

공의 이동 거리, 재생 시간, 반복 횟수를 바꿔 보세요. 예제는 기기의 ‘동작 줄이기’ 설정이 켜져 있으면 움직임을 줄입니다.
