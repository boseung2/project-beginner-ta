1. 선택자

CSS 규칙은 선택자로 대상을 고르고, 속성: 값으로 모양을 정합니다.

선택자 { 속성: 값; }      예)  p { color: red; }

예제는 <head> 안의 <style>에 CSS를 작성합니다.

자주 쓰는 선택자는 일곱 가지입니다. 이것만 알아도 대부분의 화면을 꾸밀 수 있어요.

1-2. 상속과 우선순위

상속: 글자색·글꼴·줄간격처럼 텍스트에 관한 속성은 부모에서 자식으로 내려갑니다. 여백·테두리·크기는 내려가지 않습니다.

우선순위: 한 요소에 여러 규칙이 겹치면 더 좁게 콕 집은 선택자가 이깁니다. 아래 순서만 기억하면 됩니다.

예외!important모든 것을 덮어씀. 디버깅이 어려워지니 최후 수단

2. 박스 모델 — margin · padding · border

브라우저는 모든 요소를 네 겹의 상자로 봅니다. 안쪽부터 내용(content) → 안쪽 여백(padding) → 테두리(border) → 바깥 여백(margin)입니다.

둘은 구역이 다릅니다. padding은 테두리 안쪽, margin은 테두리 바깥쪽입니다. 안쪽을 넓히면 상자의 배경색이 함께 넓어지고, 바깥쪽을 넓히면 이웃과 떨어지기만 합니다. 아래 예제에서 파란 배경이 어디까지 칠해지는지 보세요.

값을 바꿔 보세요. 개발자 도구(F12) → 요소 → 스타일 맨 아래의 박스 모델 그림에서도 네 겹을 확인할 수 있습니다.

width / height너비 / 높이
max-width / min-width최대 / 최소 너비
padding테두리 안쪽 여백
margin테두리 바깥쪽 여백
border / border-radius테두리 / 모서리 둥글기
box-sizing: border-box지정한 크기에 padding과 border를 포함
overflow: auto내용이 넘칠 때 필요한 스크롤 제공

2-1. box-sizing — width를 어디까지로 볼 것인가

width: 200px을 주면 브라우저는 기본적으로 내용 영역만 200px로 잡습니다. 그래서 padding과 border를 주면 상자가 그만큼 더 커집니다. 이 기준을 바꾸는 속성이 box-sizing이고, 값은 두 가지입니다.

content-box기본값width는 내용까지만. padding·border는 바깥에 더해져 상자가 커짐
border-box주로 쓰는 값width가 테두리까지 포함한 크기. 지정한 숫자가 곧 실제 폭
/* CSS 맨 위에 이 한 줄을 깔아 두면 크기 계산이 훨씬 쉬워집니다 */
* { box-sizing: border-box; }

이 자료의 뒤쪽 예제들도 대부분 이 한 줄로 시작합니다. 지금은 "지정한 width가 그대로 실제 폭이 된다" 정도로만 알아 두면 충분합니다.

2-2. 가운데 정렬 — 상자를 화면 중앙에

상자를 가운데 놓는 일은 두 단계입니다. 순서가 중요합니다.

1단계폭을 줄인다max-width: 640px — 남는 공간을 먼저 만든다
2단계남는 공간을 반씩margin: 0 auto — 좌우 여백을 auto로

왜 순서가 중요하냐면, block 요소는 기본적으로 가로를 꽉 채우기 때문입니다. 폭이 꽉 차 있으면 남는 공간이 0이라, margin: 0 auto를 아무리 줘도 나눠 가질 것이 없어서 아무 일도 일어나지 않습니다. 가운데 정렬이 안 되는 대부분의 이유가 이것입니다.

auto는 "남은 공간을 알아서 가져가라"는 뜻입니다. 좌우 둘 다 auto면 서로 똑같이 나눠 가지므로 상자가 정확히 가운데로 갑니다.

위아래 간격은 사정이 다릅니다. 위아래 margin은 auto를 써도 0으로 계산되어 세로 가운데로 가지 않습니다. 그래서 margin: 40px auto처럼 위아래는 숫자, 좌우는 auto로 적습니다.

상자를 가운데 놓는 것과 글자를 가운데 놓는 것은 다른 속성입니다. 글자는 text-align: center입니다.

3. 박스 배치 — display와 position

3-1. display — block과 inline

요소는 기본적으로 두 부류로 나뉩니다. block은 한 줄을 통째로 차지하고 항상 새 줄에서 시작합니다. inline은 글자처럼 흐름 안에 놓이고 내용만큼만 차지합니다.

inline-block은 둘의 중간입니다. 흐름은 inline처럼 옆으로 이어지지만, 크기는 block처럼 width·height와 위아래 padding·margin이 적용됩니다. 버튼이나 이미지가 이런 식으로 동작합니다.

blockdiv, p, h1, ul, section한 줄을 통째로 차지하고, 항상 새 줄에서 시작
inlinespan, a, b, em글자처럼 흐름 안에 놓이고, 내용만큼만 차지
inline-blockbutton, img, input옆으로 이어지면서 크기도 가짐 (둘의 중간)
none—화면에서 사라지고 공간도 차지하지 않음

아래 예제에서 세 종류 모두 같은 width: 110px을 주었습니다. inline만 width가 먹지 않는 것을 확인해 보세요.

위 span에서 inline은 width가 적용되지 않고, inline-block은 적용됩니다.

3-2. position

요소를 "흐름대로"가 아니라 기준점에서 얼마만큼 떨어진 곳에 두고 싶을 때 씁니다. 값에 따라 기준점이 달라집니다.

네 가지의 차이는 "흐름에 남아 있는가"와 "무엇을 기준으로 재는가" 두 가지뿐입니다.

static기본값흐름 그대로. top·left를 써도 무시됨
relative원래 자리 기준자리는 그대로 차지한 채, 보이는 위치만 살짝 이동
absolute페이지 기준흐름에서 빠져 자리를 비움. 지정한 좌표로 이동
fixed브라우저 화면 기준흐름에서 빠지고, 스크롤해도 같은 자리에 고정

실무에서는 relative와 absolute를 부모·자식으로 짝지어 쓰는 방법을 많이 쓰지만, 지금은 위의 네 가지 성격만 알면 충분합니다.

relative 상자를 지우면 아래 상자가 위로 올라오지만, absolute 상자를 지워도 다른 상자는 움직이지 않습니다. "자리를 남기느냐"의 차이입니다.

static기본 문서 흐름에 배치
relative원래 자리를 유지하며 위치만 조절
absolute일반 흐름에서 빠져 기준 영역에 배치
fixed브라우저 화면 기준으로 고정. 예제에서는 실행 결과 영역 기준
sticky스크롤하다 지정한 경계에 닿으면 달라붙음
top / right / bottom / left기준으로부터의 위치
z-index겹치는 요소의 쌓임 순서

5. 미디어 쿼리

같은 페이지를 폰·태블릿·데스크톱에서 다르게 보여주는 것이 반응형이고, 그 도구가 미디어 쿼리입니다. 보통 화면 폭을 몇 구간으로 나누고, 구간마다 열 개수나 여백을 바꿉니다. 구간의 경계를 브레이크포인트라고 합니다.

5-1. 먼저 보기 — 폭에 따라 열이 바뀌는 목록

위 버튼으로 실행 결과의 폭을 바꿔 보세요. 노란 안내 줄에 지금 어느 구간인지 표시됩니다. 더 넓게 보려면 새 창에서 열어 브라우저 크기를 조절하면 됩니다.

5-2. 쓰는 법 — 기본 스타일 + 구간별 덮어쓰기

패턴은 늘 같습니다. 기본 스타일을 먼저 쓰고, 그 아래에 @media 블록으로 구간별 차이만 덮어씁니다. 뒤에 쓴 규칙이 이기므로 넓은 화면 → 좁은 화면 순서로 적습니다.

/* 기본: 데스크톱 */
.card { width: 25%; }

@media (max-width: 1279px) { .card { width: 33.333%; } }   /* 노트북 */
@media (max-width: 767px)  { .card { width: 50%; } }       /* 태블릿 */
@media (max-width: 479px)  { .card { width: 100%; } }      /* 모바일 */

반대로 모바일 기본 + min-width로 넓혀 가는 "모바일 퍼스트" 방식도 많이 씁니다. 어느 쪽이든 한 방향으로만 일관되게 쓰면 됩니다.

5-3. 예제 — 좁은 화면에서 여백과 글자 크기 줄이기

위 버튼으로 실행 결과의 폭을 바꾸거나, 새 창에서 열어 브라우저 너비를 조절해 보세요.

@media (max-width: 600px)뷰포트 너비가 600px 이하일 때 적용 (데스크톱 퍼스트)
@media (min-width: 600px)뷰포트 너비가 600px 이상일 때 적용 (모바일 퍼스트)
@media (min-width: 480px) and (max-width: 767px)두 값 사이 구간에만 적용
자주 쓰는 브레이크포인트480 / 768 / 1024 / 1280px. 정해진 값은 없고 디자인에 맞춰 정함
max-width: 640px요소 너비의 상한. 미디어 쿼리 조건과는 다른 역할
viewport 메타 태그모바일에서 기기 너비에 맞게 페이지를 표시하도록 설정

6. 플렉스 박스

블록 요소는 위에서 아래로만 쌓입니다. 부모에 display: flex를 주면 자식들이 한 줄에 나란히 놓이고, 두 줄의 속성으로 가로·세로 어디에 둘지를 정할 수 있습니다. 메뉴 바, 카드 목록, 가운데 정렬은 거의 전부 이걸로 합니다.

6-1. 먼저 보기 — 같은 상자, 다른 정렬

점선 상자가 flex 컨테이너, 파란 칸이 자식들입니다. 상자와 자식은 그대로 두고 속성 한두 줄만 바꾼 결과입니다.

규칙은 두 개뿐입니다. 자식이 놓이는 방향을 주축이라 하고 justify-content로 정렬합니다. 그에 수직인 방향이 교차축이고 align-items로 정렬합니다.

6-2. 방향과 간격

flex-direction으로 주축 방향을 정하고(row 가로 / column 세로), gap으로 자식 사이 간격을 줍니다.

row를 column으로 바꾸고, gap도 조절해 보세요.

6-3. 정렬

row에서는 주축이 가로, 교차축이 세로입니다. column으로 바꾸면 축도 바뀝니다.

6-4. 줄바꿈

flex의 기본값은 flex-wrap: nowrap, 즉 줄을 바꾸지 않음입니다. 공간이 부족해도 다음 줄로 넘어가지 않고 자식들이 찌그러집니다. width를 줬는데 지켜지지 않는다면 대부분 이 때문입니다.

flex-wrap: wrap을 주면 그때부터 공간이 모자랄 때 다음 줄로 넘어갑니다. 아래 예제에서 폭을 줄여 보고, wrap을 nowrap으로 바꿔서도 확인해 보세요.

display: flex부모를 Flex 컨테이너로 설정
flex-direction주축 방향: row / column
gap자식 사이의 간격
justify-content주축 방향 정렬: flex-start / center / space-between 등
align-items교차축 방향 정렬: stretch / flex-start / center 등
flex-wrap기본값은 nowrap(줄바꿈 없음). wrap을 주어야 다음 줄로 넘어감
align-self자식 하나의 교차축 정렬을 따로 지정
추가로 살펴볼 속성
flex-grow남은 공간을 나눠 가지며 커지는 비율
flex-shrink공간이 부족할 때 기본 크기와 함께 축소량을 결정
flex-basis주축 방향의 기본 크기
flexgrow / shrink / basis 축약
align-content여러 줄 전체의 교차축 정렬. 해당 방향에 여유 공간이 있어야 차이가 보임

6-5. 미디어 쿼리와 나눠 맡기

반응형을 만들 때 "미디어 쿼리를 몇 개나 써야 하나" 고민하게 되는데, 역할을 나누면 간단합니다.

flex가 알아서양이 변하는 것한 줄에 몇 개가 들어갈지, 남는 공간을 어떻게 나눌지
미디어 쿼리로성격이 바뀌는 것가로 → 세로 전환, 글자·여백 크기 조정, 요소 숨기기

flex-wrap: wrap + flex: 1 1 200px을 쓰면 "최소 200px은 확보하되 남는 공간은 나눠 갖고, 안 들어가면 다음 줄로"가 되어 미디어 쿼리 없이도 칸 수가 알아서 바뀝니다. 그래서 카드 목록 같은 건 미디어 쿼리가 아예 필요 없습니다.

반대로 가로로 놓던 것을 세로로 바꾸는 일은 flex 혼자 못 합니다. 이건 미디어 쿼리로 flex-direction을 바꿔 줘야 합니다. 실습에서 쓸 조합이 딱 이 두 줄입니다.

폭을 줄여 보세요. 취미 칸은 미디어 쿼리 없이 저절로 줄 수가 바뀌고, 프로필은 500px에서 세로로 바뀝니다.

7. 트랜스폼 · 트랜지션 · 애니메이션

셋은 역할이 다릅니다. transform은 요소를 옮기거나 돌리거나 키우는 "변형"이고, transition은 어떤 값이 바뀔 때 그 사이를 "부드럽게" 잇는 것이며, animation은 사용자 동작 없이 "스스로" 움직이는 것입니다.

7-0. 먼저 보기

세 카드에 차례로 마우스를 올려 보세요. ①은 순간적으로 바뀌고, ②는 부드럽게 바뀌며, ③은 가만히 있어도 움직입니다.

7-1. transform — 모양과 위치 바꾸기

버튼에 마우스를 올려 보세요. :hover는 "마우스가 올라간 동안"이라는 뜻입니다.

transform으로 변형해도 주변 요소의 원래 배치 공간은 그대로입니다.

7-2. transition — 변화를 부드럽게 연결하기

같은 변화를 즉시 적용할 때와 0.3초에 걸쳐 적용할 때를 비교합니다.

translate / rotate / scale이동 / 회전 / 크기 변경
transition-property전환할 속성
transition-duration전환 시간: 0.3s 등
transition-timing-function변화 속도: ease / linear 등
transition-delay전환 시작 전 대기 시간

7-3. animation — 동작 순서와 반복 정하기

@keyframes로 시작과 끝을 정하고, animation으로 시간과 반복을 지정합니다.

@keyframes시간에 따른 스타일 정의. from / to 또는 0% / 50% / 100% 등
animation-name사용할 keyframes 이름
animation-duration한 번 재생되는 시간
animation-iteration-count반복 횟수: 숫자 / infinite
animation-direction: alternate정방향과 역방향을 번갈아 재생
animation-fill-mode: forwards재생이 끝난 뒤 마지막 스타일 유지
animation-play-staterunning / paused

공의 이동 거리(-40px), 재생 시간(0.8s), 반복(infinite)을 바꿔 보세요.

실무 팁 — 움직임에 민감한 사용자 배려하기

화면이 움직이면 어지러움을 느끼는 사용자가 있어서, 운영체제에 "동작 줄이기" 설정이 있습니다. 그 설정이 켜져 있는지 묻는 미디어 쿼리가 prefers-reduced-motion이고, 실제 서비스에서는 아래 한 블록을 넣어 줍니다. 지금 단계에서 외울 필요는 없고, "이런 게 있다" 정도로 충분합니다.

/* 사용자가 "동작 줄이기"를 켜 두었으면 애니메이션을 끕니다 */
@media (prefers-reduced-motion: reduce) {
  .ball { animation: none; }
}

비슷하게 :hover 옆에 :focus-visible을 같이 적어 두면 마우스 없이 Tab 키로 이동하는 사용자에게도 같은 효과가 보입니다. 예: button:hover, button:focus-visible { … }
