1. 선택자

CSS 규칙은 선택자로 대상을 고르고, 속성: 값으로 모양을 정합니다.

선택자 { 속성: 값; }      예)  p { color: red; }

예제는 <head> 안의 <style>에 CSS를 작성합니다.

1-1. 선택자의 종류

자주 쓰는 선택자는 일곱 가지입니다. 이것만 알아도 대부분의 화면을 꾸밀 수 있어요.

1-2. 상속과 우선순위

상속: 글자색·글꼴·줄간격처럼 텍스트에 관한 속성은 부모에서 자식으로 내려갑니다. 여백·테두리·크기는 내려가지 않습니다.

우선순위: 한 요소에 여러 규칙이 겹치면 더 구체적인 선택자가 이깁니다. 점수는 (ID, 클래스, 태그) 세 자리로 셉니다.

1순위style="…"인라인 스타일. 선택자보다 항상 강함
2순위#idID 선택자 → 1-0-0
3순위.class [attr] :hover클래스 · 속성 · 의사클래스 → 0-1-0
4순위p ::before태그 · 의사요소 → 0-0-1
같으면나중에 쓴 규칙점수가 같을 때는 아래쪽에 작성한 규칙이 적용
예외!important모든 것을 덮어씀. 디버깅이 어려워지니 최후 수단

여러 개가 합쳐지면 자리별로 더합니다. .box p는 0-1-1, #box.box p는 1-1-1이라 뒤쪽이 이깁니다.

개발자 도구 → 요소(Elements) → 스타일(Styles)에서 적용된 규칙과 취소선이 그어진 규칙을 확인해 보세요.

2. 박스 모델 — margin · padding · border

브라우저는 모든 요소를 네 겹의 상자로 봅니다. 안쪽부터 내용(content) → 안쪽 여백(padding) → 테두리(border) → 바깥 여백(margin)입니다.

헷갈리는 지점은 두 가지입니다. padding은 배경색이 칠해지고 margin은 투명하다는 것, 그리고 width는 기본적으로 내용 영역만을 뜻해서 padding과 border를 더하면 실제 크기가 커진다는 것입니다. 아래 예제에서 같은 width: 200px이 왜 다른 크기로 보이는지 확인해 보세요.

padding과 margin 값을 각각 바꿔 보세요. 개발자 도구의 박스 모델에서도 차이를 확인할 수 있습니다.

width / height너비 / 높이
max-width / min-width최대 / 최소 너비
padding테두리 안쪽 여백
margin테두리 바깥쪽 여백
border / border-radius테두리 / 모서리 둥글기

3. 박스 배치 — display와 position

3-1. display — block과 inline

요소는 기본적으로 두 부류로 나뉩니다. block은 한 줄을 통째로 차지하고 항상 새 줄에서 시작합니다. inline은 글자처럼 흐름 안에 놓이고 내용만큼만 차지합니다.

inline-block은 둘의 중간입니다. 흐름은 inline처럼 옆으로 이어지지만, 크기는 block처럼 width·height와 위아래 padding·margin이 적용됩니다. 버튼이나 이미지가 이런 식으로 동작합니다.

blockdiv, p, h1, ul, section줄바꿈 O · width/height O · 상하 margin/padding O
inlinespan, a, b, em줄바꿈 X · width/height X · 상하 margin/padding 반영 안 됨
inline-blockbutton, img, input줄바꿈 X · width/height O · 상하 margin/padding O
none—화면에서 사라지고 공간도 차지하지 않음

아래 예제에서 세 종류 모두 같은 width: 110px을 주었습니다. inline만 width가 무시되는 것을 확인해 보세요.

위 span에서 inline은 width가 적용되지 않고, inline-block은 적용됩니다.

3-2. position

요소를 "흐름대로"가 아니라 기준점에서 얼마만큼 떨어진 곳에 두고 싶을 때 씁니다. 값에 따라 기준점이 달라집니다.

가장 흔한 조합은 부모 relative + 자식 absolute입니다. 부모에 relative를 주면 자식 absolute의 기준점이 그 부모가 되어, 카드 모서리에 배지를 붙이는 식의 배치가 됩니다. 아래 예제의 NEW 배지가 그 경우입니다.

5. 미디어 쿼리

같은 페이지를 폰·태블릿·데스크톱에서 다르게 보여주는 것이 반응형이고, 그 도구가 미디어 쿼리입니다. 보통 화면 폭을 몇 구간으로 나누고, 구간마다 열 개수나 여백을 바꿉니다. 구간의 경계를 브레이크포인트라고 합니다.

5-1. 먼저 보기 — 폭에 따라 열이 바뀌는 목록

위 버튼으로 실행 결과의 폭을 바꿔 보세요. 노란 안내 줄에 지금 어느 구간인지 표시됩니다. 더 넓게 보려면 새 창에서 열어 브라우저 크기를 조절하면 됩니다.

5-2. 쓰는 법 — 기본 스타일 + 구간별 덮어쓰기

패턴은 늘 같습니다. 기본 스타일을 먼저 쓰고, 그 아래에 @media 블록으로 구간별 차이만 덮어씁니다. 뒤에 쓴 규칙이 이기므로 넓은 화면 → 좁은 화면 순서로 적습니다.

/* 기본: 데스크톱 */
.card { width: 25%; }

@media (max-width: 1279px) { .card { width: 33.333%; } }   /* 노트북 */
@media (max-width: 767px)  { .card { width: 50%; } }       /* 태블릿 */
@media (max-width: 479px)  { .card { width: 100%; } }      /* 모바일 */

반대로 모바일 기본 + min-width로 넓혀 가는 "모바일 퍼스트" 방식도 많이 씁니다. 어느 쪽이든 한 방향으로만 일관되게 쓰면 됩니다.

6. 플렉스 박스

블록 요소는 위에서 아래로만 쌓입니다. 부모에 display: flex를 주면 자식들이 한 줄에 나란히 놓이고, 두 줄의 속성으로 가로·세로 어디에 둘지를 정할 수 있습니다. 메뉴 바, 카드 목록, 가운데 정렬은 거의 전부 이걸로 합니다.

6-1. 먼저 보기 — 같은 상자, 다른 정렬

점선 상자가 flex 컨테이너, 파란 칸이 자식들입니다. 상자와 자식은 그대로 두고 속성 한두 줄만 바꾼 결과입니다.

규칙은 두 개뿐입니다. 자식이 놓이는 방향을 주축이라 하고 justify-content로 정렬합니다. 그에 수직인 방향이 교차축이고 align-items로 정렬합니다.

6-2. 방향과 간격

flex-direction으로 주축 방향을 정하고(row 가로 / column 세로), gap으로 자식 사이 간격을 줍니다.

row를 column으로 바꾸고, gap도 조절해 보세요.

6-3. 정렬

row에서는 주축이 가로, 교차축이 세로입니다. column으로 바꾸면 축도 바뀝니다.

6-4. 줄바꿈

display: flex부모를 Flex 컨테이너로 설정
flex-direction주축 방향: row / column
gap자식 사이의 간격
justify-content주축 방향 정렬: flex-start / center / space-between 등
align-items교차축 방향 정렬: stretch / flex-start / center 등
flex-wrap: wrap공간이 부족하면 다음 줄로 배치
align-self자식 하나의 교차축 정렬을 따로 지정
추가로 살펴볼 속성
flex-grow남은 공간을 나눠 가지며 커지는 비율
flex-shrink공간이 부족할 때 기본 크기와 함께 축소량을 결정

7. 트랜스폼 · 트랜지션 · 애니메이션

셋은 역할이 다릅니다. transform은 요소를 옮기거나 돌리거나 키우는 "변형"이고, transition은 어떤 값이 바뀔 때 그 사이를 "부드럽게" 잇는 것이며, animation은 사용자 동작 없이 "스스로" 움직이는 것입니다.

7-0. 먼저 보기

세 카드에 차례로 마우스를 올려 보세요. ①은 순간적으로 바뀌고, ②는 부드럽게 바뀌며, ③은 가만히 있어도 움직입니다.

7-1. transform — 모양과 위치 바꾸기

버튼에 마우스를 올리거나, Tab 키로 포커스를 옮겨 보세요.

transform으로 변형해도 주변 요소의 원래 배치 공간은 그대로입니다.

7-2. transition — 변화를 부드럽게 연결하기

같은 변화를 즉시 적용할 때와 0.3초에 걸쳐 적용할 때를 비교합니다.

translate / rotate / scale이동 / 회전 / 크기 변경
transition-property전환할 속성
transition-duration전환 시간: 0.3s 등
transition-timing-function변화 속도: ease / linear 등
transition-delay전환 시작 전 대기 시간

7-3. animation — 동작 순서와 반복 정하기

@keyframes로 시작과 끝을 정하고, animation으로 시간과 반복을 지정합니다.

@keyframes시간에 따른 스타일 정의. from / to 또는 0% / 50% / 100% 등
animation-name사용할 keyframes 이름
animation-duration한 번 재생되는 시간
animation-iteration-count반복 횟수: 숫자 / infinite
animation-direction: alternate정방향과 역방향을 번갈아 재생
animation-fill-mode: forwards재생이 끝난 뒤 마지막 스타일 유지
animation-play-staterunning / paused

공의 이동 거리, 재생 시간, 반복 횟수를 바꿔 보세요. 예제는 기기의 ‘동작 줄이기’ 설정이 켜져 있으면 움직임을 줄입니다.
