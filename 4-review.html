0. 지금까지 — 한 장으로 다시 보기

3주 동안 배운 HTML · CSS · JS가 한 화면에서 어떻게 이어지는지, 3주차 실습의 취미 추가 · 삭제로 다시 봅니다. 먼저 취미를 추가하고, 눌러서 지워 보세요.

0-1. 먼저 보기 — 취미 추가 · 삭제의 흐름

HTML에서 이름(id · class)을 주고 → JS가 찾아 event listener를 붙이고 → li를 만들어 붙이거나 지운다 → CSS가 모양을 입힌다

1. TypeScript 맛보기 — 실행 전에 검사하는 JS

TypeScript(TS)는 JS에 타입을 적을 수 있게 한 언어입니다. 코드를 실행하기 전에 검사해서, 타입이 맞지 않는 곳을 미리 빨간 줄로 알려 줍니다. 자세한 문법은 5주차에 봅니다.

1-1. 먼저 보기 — 타입이 없을 때와 있을 때

같은 덧셈 함수를 타입 없이, 그리고 타입을 붙여 씁니다. 오른쪽 타입 검사에는 TS가 실행 전에 찾은 빨간 줄이 나옵니다.

타입을 안 줌function add(a, b)a, b가 무엇인지 몰라 빨간 줄 (implicitly has an 'any' type)
타입을 줌function addNum(a: number, b: number)숫자 자리에 "1"을 넣으면 빨간 줄
JS로 실행하면add("1", 2)오류 없이 12 — 글자 "1"에 2가 이어 붙음

입력칸의 값(input.value)은 늘 글자입니다. 이런 실수를 TS는 실행하기 전에 빨간 줄로 알려 줍니다.

1-2. 실행 흐름 — .ts → .js

브라우저는 TS를 바로 실행하지 못합니다. TS 컴파일러(tsc)가 검사한 뒤 타입을 지운 JS로 바꾸고, 브라우저는 그 JS를 실행합니다.

app.ts  →  tsc: 타입 검사 + 타입 지우기  →  app.js  →  브라우저에서 실행
           (틀리면 빨간 줄)

TS Playground ↗는 설치 없이 바로 TS를 쓸 수 있습니다. 1-1 예제의 [Playground에서 열기 ↗]를 눌러 타입을 지우거나 바꿔 보세요. 내 컴퓨터에 설치하는 것은 5주차에 합니다.

왼쪽TS 코드. 빨간 줄에 마우스를 올리면 오류 메시지
오른쪽 .JS 탭타입을 지운 JS — 브라우저가 실제로 실행하는 코드
Run → Logs 탭실행해서 console.log 결과 보기
Errors 탭오류 목록. 영어로 나옴 — 이 페이지 타입 검사 칸의 회색 영어 줄과 같은 문장

2. 실습: 할 일 목록

시작 코드에 HTML과 JS를 채워 목표 화면을 만듭니다. 1~4부까지 하면 완료이고, 5부는 Advanced입니다.

2-1. 목표 화면 · 시작 코드

시작 코드를 복사해 todo.html로 저장하고 Live Server로 엽니다.

1부 · HTML

  1. class="todo"인 div를 만든다.
  2. 그 안에 h1 "오늘 할 일"을 넣는다.
  3. class="add-row"인 div를 만들고, 그 안에 id="todo-input"인 input과 id="add-btn"인 button을 넣는다.
  4. class="todo-list"인 ul을 만들고 li 세 개를 넣는다.
  5. 끝낸 일 li에는 class="done"을 준다.

2부 · 할 일 추가 (JS)

  1. input, button, ul을 querySelector로 찾는다.
  2. button에 click event listener를 붙인다.
  3. 그 안에서 input 값을 읽는다. 빈칸이면 return.
  4. li를 만들어 글자를 넣고 .todo-list 끝에 붙인다.
  5. input을 비운다.

3부 · 끝낸 일 표시 (JS)

  1. 원래 있는 li마다 click event listener를 붙인다.
  2. 누르면 li의 done 클래스를 켜고 끈다.
  3. 2부에서 새로 만든 li에도 같은 event listener를 붙인다.

4부 · 박수 치기 (HTML · JS)

  1. 목록 아래에 class="clap-row"인 div를 만들고, 그 안에 id="clap-btn"인 button("오늘 할 일을 끝냈어요 👏")과 id="reset-btn"인 button("초기화")을 넣는다.
  2. 그 아래 class="claps"인 p를 만들고, "박수 <span id="clap-count">0</span>번 <span id="clap-icons"></span>"을 넣는다.
  3. 박수 횟수를 담을 변수를 let으로 만든다.
  4. clap-btn에 click event listener를 붙인다. 횟수를 1 늘려 clap-count에 넣고, clap-icons 글자 끝에 👏를 하나 붙인다.
  5. reset-btn에 click event listener를 붙인다. 횟수는 0, clap-count는 0, clap-icons는 빈 글자로 만든다.

5부 (Advanced) · 할 일 수정하기

할 일을 두 번 누르면 입력칸에 그 글자가 들어가고 [추가]가 [수정]으로 바뀝니다. 고친 뒤 [수정]을 누르면 그 할 일이 바뀝니다.

  1. 수정 중인 li를 기억할 변수 let editing = null;을 만든다.
  2. li에 dblclick event listener를 붙인다. 그 안에서 input에 li 글자를 넣고, editing = li, 버튼 글자를 "수정"으로 바꾼다.
  3. 2부의 버튼 click 안, 빈칸 검사 다음을 아래처럼 나눈다.
if (editing) {
  // editing의 글자를 입력값으로 바꾸고, editing = null, 버튼 글자는 "추가"로
} else {
  // 원래 하던 추가
}
  1. 새로 만든 li에도 dblclick event listener를 붙인다.

완료 확인

  • 목표 화면과 같은 모양
  • 추가하면 목록 끝에 붙고 입력칸이 비워짐 · 빈칸이면 안 붙음
  • 원래 할 일과 새 할 일 모두 눌러서 줄 긋기 · 되돌리기
  • 박수를 누를 때마다 횟수가 1씩 늘고 👏가 하나씩 붙음 · 초기화하면 0
  • 콘솔에 빨간 줄 없음

[추가] 버튼을 눌렀을 때 일어나는 일을 내 코드로 설명하면 먼저 나가도 됩니다.
