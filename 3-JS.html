2. 함수의 여러 가지 모양

함수는 만들어 두고(정의) 필요할 때 불러서(호출) 씁니다. JS는 같은 함수를 여러 모양으로 쓰고, React에는 화살표 모양이 가장 많이 나옵니다.

정의:  function 이름(재료) { 할 일; return 결과; }      호출:  이름(값)

2-1. 함수 선언 — 매개변수 · return · 기본값

괄호 안의 매개변수로 재료를 받고, return으로 결과를 돌려줍니다. return을 만나면 함수는 그 자리에서 끝납니다.

호출greet("홍길동")괄호를 붙여야 실행됨
돌려주기return 값;결과를 돌려주고 끝냄
멈추기if (text === "") return;여기서 끝냄. 아래 줄은 실행되지 않음
기본값(name = "손님")값을 넘기지 않으면 쓰는 값

결과가 undefined로 나오면 return을 빠뜨린 것입니다. if (…) return;은 실습 2부에서 빈칸을 막을 때 씁니다.

2-2. 표현식 · 화살표 — 같은 함수, 네 가지 모양

아래 1~4는 모양만 다른 같은 덧셈 함수입니다.

function (a, b) { … }   →   (a, b) => { … }   →   (a, b) => a + b        재료가 없으면  () => { … }
1. 선언function add(a, b) { … }가장 기본 모양
2. 표현식const add = function (a, b) { … };이름 없는 함수를 변수에 담음
3. 화살표const add = (a, b) => { … };function 대신 =>
4. 한 줄 화살표const add = (a, b) => a + b;중괄호와 return을 함께 뺌

3장부터 이벤트 함수는 () => { … } 모양으로 씁니다.

2-3. 함수를 넘기기 — 괄호가 있고 없고

함수도 값이라서 다른 함수에 넘길 수 있습니다. 넘길 때는 괄호 없이 이름만 씁니다.

넘길 때:  sayHi        부를 때:  sayHi()
이름으로 넘기기setTimeout(sayHi, 1000)1초 뒤에 불러 줌
만들어 넘기기setTimeout(() => { … }, 2000)넘기는 자리에서 만듦
잘못된 예setTimeout(sayHi(), 1000)괄호를 붙이면 지금 바로 실행됨
클릭할 때addEventListener("click", 함수)누를 때마다 불러 줌(3장)
칸마다 바로배열.forEach(함수)칸마다 그 자리에서 불러 줌

setTimeout은 기다리지 않고 다음 줄로 넘어가서, 4 · 5번이 맨 나중에 찍힙니다.

3. 이벤트 — 언제 실행할까

지금까지 본 코드는 대부분 페이지가 열릴 때 한 번 실행됐습니다. 이벤트는 "버튼을 클릭했을 때"처럼 코드를 실행할 때를 정합니다.

요소.addEventListener("이벤트 이름", 실행할 함수);
예)  button.addEventListener("click", () => { … });

3-1. 먼저 보기 — 선택 → 이벤트 → 변경

0장에서 본 교내공지 접기 버튼입니다. 1. 쓸 요소를 집고 → 2. 언제 실행할지 정하고 → 3. 화면을 바꿉니다. 버튼을 눌러 보세요.

1. 선택document.querySelector("#toggle")쓸 요소를 집어 변수에 담기
2. 이벤트button.addEventListener("click", …)클릭하면 넘겨 둔 함수 실행
3. 변경list.hidden = !list.hidden숨김을 뒤집기(! = 반대로)
3. 변경button.textContent = 조건 ? A : B상태에 맞는 글자로 바꾸기
선택 → 이벤트 → 변경      실습 1·2·3부가 모두 이 순서입니다

3-2. 자주 쓰는 이벤트 — addEventListener

버튼을 누르고, 입력칸에 적고, 회색 상자에 마우스를 올려 보세요. 콘솔에 이벤트 이름이 찍힙니다.

3-3. 이벤트 객체 — event.target · event.key

이벤트가 일어나면 브라우저가 무슨 일이 있었는지 담은 객체를 함수에 넘겨 줍니다. 괄호 안에 이름을 적어 받습니다: (event) => { … }. 입력칸에 적고 Enter를 눌러 보세요.

3-4. 폼 제출 — submit · preventDefault

입력칸과 버튼을 <form>으로 감싸면 Enter만 쳐도 제출(submit)됩니다. 제출하면 페이지가 새로고침되므로 event.preventDefault()로 막습니다.

form + "submit"이벤트는 버튼이 아니라 form에 붙임. 클릭과 Enter를 한 번에 받음
event.preventDefault()새로고침 막기. 함수 첫 줄에
.trim()앞뒤 공백 지우기. 공백만 적었으면 ""이 됨

실습은 form 없이 type="button" 버튼만 써서 preventDefault가 없어도 됩니다.

4. DOM — 요소 찾고 바꾸기

브라우저는 HTML을 읽어 요소들을 나무 모양으로 이어 둡니다. 이것이 DOM(Document Object Model)입니다. JS는 HTML 파일이 아니라 이 나무를 바꿉니다. 그래서 새로고침하면 처음으로 돌아옵니다.

4-1. DOM 나무

실습 시작 코드(7장)를 나무로 그리면 이렇습니다. 감싼 태그가 부모, 안에 든 태그가 자식입니다. 파란 마디는 실습에서 JS가 집을 요소입니다.

F12 → 요소(Elements) 탭이 이 나무입니다. JS로 바꾸면 여기가 바뀝니다.

4-2. 요소 찾기 — querySelector · querySelectorAll

요소는 CSS 선택자를 그대로 써서 찾습니다. 하나만 집으면 querySelector, 모두 집으면 querySelectorAll입니다.

선택자는 CSS와 똑같이:   태그 "h1"    클래스 ".highlight"    id "#intro"
하나document.querySelector("선택자")맞는 요소 중 첫 번째 하나
전부document.querySelectorAll("선택자")맞는 요소 모두를 담은 목록(NodeList)
하나씩items.forEach((el) => { … })전부 집은 것을 하나씩 꺼내 같은 일 하기
못 찾으면nullnull 뒤에 점(.)을 붙이면 오류

막히는 지점: Cannot read properties of null이 뜨면 선택자 오타이거나 script가 그 요소보다 위에 있는 것입니다.

4-3. 글자와 값 — textContent · value · 속성

태그 안의 글자는 textContent, 입력칸에 적힌 값은 value입니다.

6-3. 구조 분해 할당

6-4. 스프레드와 불변성

...(스프레드)는 배열이나 객체를 펼쳐 새 배열 · 새 객체를 만듭니다. 원본은 그대로입니다.

React 상태는 고치지 말고 새로 만든다:   list.push(x)  (X)   →   [...list, x]  (O)
배열에 더하기[...arr, x]새 배열. 원본은 그대로
객체 고치기{ ...obj, age: 22 }복사한 뒤 age만 바꾼 새 객체
원본 바꾸기arr.push(x)React 상태에는 쓰지 않습니다

React는 새 배열 · 새 객체가 들어와야 바뀐 것을 알아챕니다(불변성).

6-5. map · filter

배열의 칸마다 함수를 불러 새 배열을 만듭니다. map은 칸마다 바꾸고, filter는 조건에 맞는 칸만 남깁니다.

칸마다 바꾸기arr.map((h) => …)개수가 같은 새 배열. React에서 목록을 그릴 때
골라 남기기arr.filter((h) => 조건)조건이 참인 칸만. React에서 삭제할 때

6-6. async · await · fetch

서버에 데이터를 요청하고, 응답이 오면 화면에 넣습니다. [불러오기]를 눌러 보세요.

요청fetch(url)응답은 조금 뒤에 옵니다
기다리기await응답이 올 때까지 기다립니다. async 함수 안에서 씁니다
JSON → 객체await res.json()받은 글자를 객체로 바꿉니다
실패 대비try { … } catch (error) { … }오류가 나면 catch로 건너뜁니다

6-7. import · export

한 파일에서 내보낸(export) 것을 다른 파일에서 가져와(import) 씁니다. 여기서는 실행하지 않고 코드만 봅니다.

profile.js — 내보내는 쪽

export function greet(who) {
  return `안녕하세요, ${who}님`;
}

export default function intro() {
  return "저는 홍길동입니다";
}

main.js — 가져오는 쪽

import intro, { greet } from "./profile.js";

console.log(greet("홍길동"));   // 안녕하세요, 홍길동님
console.log(intro());          // 저는 홍길동입니다
이름 붙여 내보내기export function greet가져올 때 중괄호에 같은 이름으로
기본 내보내기export default파일마다 하나. 가져올 때 이름은 마음대로

2일차 파일에 이어 쓰려면?

클래스 이름을 .card · .profile · .hobbies로 맞춘 경우에만 됩니다. 시작 코드에서 3일차 추가 주석이 달린 곳만 내 파일의 같은 자리로 옮기세요. 헷갈리면 시작 코드로 새로 시작하세요.

1부 · 버튼으로 어둡게 보기 켜고 끄기

'어둡게 보기' 버튼(#mode-btn)을 누를 때마다 카드(.card)에 dark 클래스를 붙였다 뗐다 합니다.

버튼 글자도 상태에 맞게 '어둡게 보기' ↔ '밝게 보기'로 바꿉니다.

참고: 3-1 선택 → 이벤트 → 변경 · 4-2 요소 찾기 · 4-4 classList · 1-3 비교와 조건
막히는 지점:

  • classList에는 점 없이 씁니다. toggle(".dark")는 오류는 안 나지만 색이 안 바뀝니다.
  • Cannot read properties of null이 뜨면 선택자의 # · .이나 이름이 틀린 것입니다.

2부 · 취미 추가하기

'추가' 버튼(#add-btn)을 누르면 입력칸(#hobby-input)의 글자로 li를 만들어 .hobbies 끝에 붙이고, 입력칸을 비웁니다.

빈칸이면 아무것도 붙이지 않습니다. if (값 === "") return;이나 if (값 !== "") { … } 중 편한 쪽을 쓰세요.

참고: 5-1 추가 · 4-3 글자와 값 · 1-3 비교와 조건 · 2-1 return · 3-4 trim
막히는 지점:

  • 입력값은 클릭 함수 안에서 읽습니다. 바깥에서 읽으면 늘 빈 값입니다.
  • li도 클릭 함수 안에서 만듭니다. 바깥에서 만들면 칸이 하나만 생기고 글자만 바뀝니다.
  • 괄호 · 따옴표 하나만 틀려도 script 전체가 멈춥니다. 콘솔의 첫 빨간 줄부터 보세요.

3부 · 누르면 지워지는 취미

취미 칸을 누르면 그 취미가 지워지게 합니다. 원래 있던 네 개부터 해 봅니다.

2부에서 추가한 취미도 지워지게 합니다.

참고: 4-2 querySelectorAll · forEach · 5-2 '새 공지도 지워지게' · 2-3 함수를 넘기기
막히는 지점:

  • querySelectorAll 목록에 addEventListener를 바로 붙이면 is not a function 오류가 납니다. forEach로 하나씩 붙이세요.
  • 새로 만든 li에는 이벤트가 없습니다. 2부에서 li를 만드는 자리에서 붙이세요.

완료 확인: 아래 네 가지를 TA에게 보여 주고, 내 코드에서 선택 · 이벤트 · 변경에 해당하는 줄을 짚어 설명하면 먼저 나가도 됩니다.

  • 어둡게 보기 버튼을 두 번 누르면 카드와 버튼 글자가 원래대로 돌아옵니다.
  • 취미를 추가하면 목록 끝에 붙고 입력칸이 비워집니다. 빈칸이면 붙지 않습니다.
  • 원래 취미와 새 취미 모두 누르면 지워집니다.
  • 콘솔에 빨간 줄이 없습니다.

AI에게 물을 때는 요소 이름과 동작을 함께 적습니다. 예: "#mode-btn을 누르면 .card에 dark 클래스를 켜고 끄는 코드를 써 줘."
