1. 기본 문법 — C · Python과 다른 점

C · Python과 같은 부분은 넘어가고, JS에서 모양이 다른 곳만 빠르게 훑습니다.

<script>는 </body> 바로 위에 — 화면 요소가 다 만들어진 다음에 실행되도록

1-1. 한 번에 훑기 — 변수 · 자료형 · 비교 · 반복

결과는 콘솔에 나옵니다. 이 페이지에서는 '콘솔' 칸, 내 파일에서는 F12 (Mac: Cmd+Option+I) → Console 탭입니다.

변수 선언const name = "홍길동"; let age = 21;C: int age = 21; / Python: age = 21 — JS는 타입을 적지 않고, 바뀔 값만 let
문자열 포맷`${name}, ${age}세`C: printf("%s, %d세", …) / Python: f"{name}, {age}세"
같다 비교a === b · a !== bC · Python: == · !=
삼항조건 ? A : BC: 같음 / Python: A if 조건 else B
목록["테니스", "산책"] · hobbies.lengthC: 배열 / Python: list · len(hobbies)
키-값{ name: "홍길동", age: 22 } · me.nameC: struct / Python: dict · me["name"]
없음undefined · nullC: NULL / Python: None — 값을 안 넣으면 undefined
출력console.log(a, b)C: printf / Python: print(a, b)
반복for (const x of arr) { … }C: for (int i = 0; …) / Python: for x in arr:

JS의 ==는 타입을 바꿔 비교해서 "22" == 22도 true입니다. 비교는 항상 ===로 씁니다.

alert · confirm · prompt는 페이지 위에 작은 창을 띄웁니다. ▶ 실행을 눌러 보세요.

JS를 별도 파일로 분리하려면?

HTML과 JS 파일을 같은 폴더에 두세요. main.js에는 <script> 태그 없이 코드만 씁니다.

JS 함수는 모양이 여럿이고, 값처럼 다른 함수에 넘길 수 있습니다.

2-1. 함수의 여러 모양과 함수 넘기기

①~④가 함수의 네 가지 모양이고, 아래쪽이 함수를 넘기는 예입니다. 3장 이벤트와 React에는 ③ 화살표 모양이 가장 많이 나옵니다.

3. 이벤트 — 언제 실행할까

지금까지 본 코드는 대부분 페이지가 열릴 때 한 번 실행됐습니다. 이벤트는 "버튼을 클릭했을 때"처럼 코드를 실행할 때를 정합니다.

요소.addEventListener("이벤트 이름", 실행할 함수);
예)  button.addEventListener("click", () => { … });

3-1. 먼저 보기 — 선택 → 이벤트 → 변경

0장에서 본 교내공지 접기 버튼입니다. 1. 쓸 요소를 집고 → 2. 언제 실행할지 정하고 → 3. 화면을 바꿉니다. 버튼을 눌러 보세요.

1. 선택document.querySelector("#toggle")쓸 요소를 집어 변수에 담기
2. 이벤트button.addEventListener("click", …)클릭하면 넘겨 둔 함수 실행
3. 변경list.hidden = !list.hidden숨김을 뒤집기(! = 반대로)
3. 변경button.textContent = 조건 ? A : B상태에 맞는 글자로 바꾸기

3-2. 이벤트 종류 · 이벤트 객체 · 폼 제출

함수 괄호 안에 event를 적으면 브라우저가 무슨 일이 있었는지(누른 키, 일어난 요소)를 넘겨 줍니다. 버튼을 누르고, 입력칸에 영어로 적은 뒤 Enter를 쳐 보세요. 공백만 적고 Enter도 쳐 보세요.

click클릭할 때

event.key누른 키 이름("Enter", "a" …)

4. DOM — 요소 찾고 바꾸기

브라우저는 HTML을 읽어 요소들을 나무 모양으로 이어 둡니다. 이것이 DOM(Document Object Model)입니다. JS는 HTML 파일이 아니라 이 나무를 바꿉니다. 그래서 새로고침하면 처음으로 돌아옵니다.

4-1. DOM 나무

실습 시작 코드(7장)를 나무로 그리면 이렇습니다. 감싼 태그가 부모, 안에 든 태그가 자식입니다. 파란 마디는 실습에서 JS가 집을 요소입니다.

F12 → 요소(Elements) 탭이 이 나무입니다. JS로 바꾸면 여기가 바뀝니다.

4-2. 요소 찾기 — querySelector · querySelectorAll

요소는 CSS 선택자를 그대로 써서 찾습니다. 하나만 집으면 querySelector, 모두 집으면 querySelectorAll입니다.

선택자는 CSS와 똑같이:   태그 "h1"    클래스 ".highlight"    id "#intro"
하나document.querySelector("선택자")맞는 요소 중 첫 번째 하나
전부document.querySelectorAll("선택자")맞는 요소 모두를 담은 목록(NodeList)
하나씩items.forEach((el) => { … })전부 집은 것을 하나씩 꺼내 같은 일 하기
못 찾으면nullnull 뒤에 점(.)을 붙이면 오류

막히는 지점: Cannot read properties of null이 뜨면 선택자 오타이거나 script가 그 요소보다 위에 있는 것입니다.

4-3. 글자와 값 — textContent · value · 속성

태그 안의 글자는 textContent, 입력칸에 적힌 값은 value입니다.

요소.textContent태그 안의 글자 읽기 · 바꾸기
입력칸.value입력칸에 지금 적힌 글자
입력칸.value = ""입력칸 비우기
요소.hidden = true속성 바꾸기. true면 숨김, false면 보임

막히는 지점: 값을 읽는 줄이 클릭 함수 바깥에 있으면 늘 빈 값이 됩니다.

4-4. 모양 — classList · style

모양은 CSS에 클래스로 적어 두고, JS는 그 클래스를 붙였다 뗐다 합니다. style로 직접 바꿀 수도 있습니다.

querySelector에는 점을 붙여 ".box",     classList에는 점 없이 "highlight"

떼기el.classList.remove("highlight")클래스 떼기
켜고 끄기el.classList.toggle("highlight")없으면 붙이고, 있으면 뗌

6-4. import · export

한 파일에서 내보낸(export) 것을 다른 파일에서 가져와(import) 씁니다. 여기서는 실행하지 않고 코드만 봅니다.

profile.js — 내보내는 쪽

export function greet(who) {
  return `안녕하세요, ${who}님`;
}

export default function intro() {
  return "저는 홍길동입니다";
}

main.js — 가져오는 쪽

import intro, { greet } from "./profile.js";

console.log(greet("홍길동"));   // 안녕하세요, 홍길동님
console.log(intro());          // 저는 홍길동입니다
이름 붙여 내보내기export function greet가져올 때 중괄호에 같은 이름으로
기본 내보내기export default파일마다 하나. 가져올 때 이름은 마음대로

2부 · 취미 추가하기

'추가' 버튼(#add-btn)을 누르면 입력칸(#hobby-input)의 글자로 li를 만들어 .hobbies 끝에 붙이고, 입력칸을 비웁니다.

빈칸이면 아무것도 붙이지 않습니다. if (값 === "") return;이나 if (값 !== "") { … } 중 편한 쪽을 쓰세요.

참고: 5-1 추가 · 삭제 · 4-3 글자와 값 · 1-1 비교 · 조건 · 2-1 함수(return) · 3-2 trim
막히는 지점:

  • 입력값은 클릭 함수 안에서 읽습니다. 바깥에서 읽으면 늘 빈 값입니다.
  • li도 클릭 함수 안에서 만듭니다. 바깥에서 만들면 칸이 하나만 생기고 글자만 바뀝니다.
  • 괄호 · 따옴표 하나만 틀려도 script 전체가 멈춥니다. 콘솔의 첫 빨간 줄부터 보세요.

3부 · 누르면 지워지는 취미

취미 칸을 누르면 그 취미가 지워지게 합니다. 원래 있던 네 개부터 해 봅니다.

2부에서 추가한 취미도 지워지게 합니다.

참고: 4-2 querySelectorAll · forEach · 5-1 아래 '새 공지도 지워지게' · 2-1 함수 넘기기
막히는 지점:

  • querySelectorAll 목록에 addEventListener를 바로 붙이면 is not a function 오류가 납니다. forEach로 하나씩 붙이세요.
  • 새로 만든 li에는 이벤트가 없습니다. 2부에서 li를 만드는 자리에서 붙이세요.

완료 확인: 아래 네 가지를 TA에게 보여 주고, 내 코드에서 선택 · 이벤트 · 변경에 해당하는 줄을 짚어 설명하면 먼저 나가도 됩니다.

  • 어둡게 보기 버튼을 두 번 누르면 카드와 버튼 글자가 원래대로 돌아옵니다.
  • 취미를 추가하면 목록 끝에 붙고 입력칸이 비워집니다. 빈칸이면 붙지 않습니다.
  • 원래 취미와 새 취미 모두 누르면 지워집니다.
  • 콘솔에 빨간 줄이 없습니다.

AI에게 물을 때는 요소 이름과 동작을 함께 적습니다. 예: "#mode-btn을 누르면 .card에 dark 클래스를 켜고 끄는 코드를 써 줘."

4부 (Advanced) · Enter로 추가하고 취미 개수 세기

여기부터는 추가 사항입니다. 1~3부 완료 확인을 받은 뒤 더 해 보고 싶으면 이어서 하세요.

입력칸에서 Enter를 쳐도 추가되게 합니다. 2부 코드를 addHobby() 함수로 묶어 버튼 클릭과 Enter 두 곳에서 부릅니다.

취미 위의 "취미 4개"가 추가하거나 지울 때마다 바뀌게 합니다. 개수를 다시 쓰는 코드도 함수(updateCount())로 묶어 필요한 곳에서 부릅니다.

참고: 2-1 함수 넘기기 · 3-2 event.key · 4-2 querySelectorAll · 1-1 .length
막히는 지점:

  • addEventListener("click", addHobby())처럼 괄호를 붙이면 그 자리에서 한 번 실행되고, 클릭해도 반응이 없습니다.
  • 한글을 치고 Enter를 누르면 두 번 추가될 수 있습니다. keydown 함수 첫 줄에 if (event.isComposing) return;을 넣으세요.
  • 개수는 지운 직후에도 다시 세야 합니다(3부의 remove() 다음 줄).

5부 (Advanced) · 날씨 API로 지금 기온 보여 주기

[오늘 날씨]를 누르면 날씨 API에서 전주의 지금 기온을 받아 옆에 "전주 지금 16.8°C"처럼 씁니다. 받는 동안에는 "불러오는 중…", 실패하면 "불러오지 못했습니다"를 씁니다.

https://api.open-meteo.com/v1/forecast?latitude=35.85&longitude=127.13&current=temperature_2m

순서는 네 단계입니다. 먼저 3단계까지만 쓰고 콘솔에서 데이터 모양을 본 뒤 4단계로 꺼냅니다.

1. 요청const res = await fetch(url);주소로 요청하고 응답이 올 때까지 기다림
2. JSON → 객체const data = await res.json();받은 글자를 JS 객체로 바꿈
3. 모양 보기console.log(data);콘솔에서 ▶를 눌러 펼쳐 봄
4. 꺼내기data.current.temperature_2m점(.)으로 한 단계씩 안으로 들어감

콘솔에 찍히는 데이터는 이런 모양입니다(줄임). { } 안에 또 { }가 있는 객체입니다. 이 주소를 브라우저 주소창에 열어도 같은 내용이 보입니다.

{
  "latitude": 35.85,
  "longitude": 127.125,
  "current_units": { "temperature_2m": "°C", … },
  "current": {
    "time": "2026-10-01T09:15",
    "temperature_2m": 16.8
  }
}
위도data.latitude35.85
지금 날씨 묶음data.current{ time, interval, temperature_2m } 객체
지금 기온data.current.temperature_2m16.8 (숫자)
기온 단위data.current_units.temperature_2m"°C"

1-1의 me.name과 같은 규칙입니다. 한 단계 안에 있으면 점을 한 번 더 붙입니다.

참고: 6-3 async · await · fetch · 1-1 객체에서 꺼내기
막히는 지점:

  • await는 async 함수 안에서만 씁니다. 화살표 함수면 async () => { … }입니다.
  • undefined나 [object Object]가 보이면 꺼내는 경로가 틀린 것입니다. console.log(data)로 모양부터 보세요.
