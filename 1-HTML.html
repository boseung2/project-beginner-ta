HTML

초급프로젝트 보충 세미나 1회차 · 왼쪽은 코드, 오른쪽은 그 코드를 브라우저가 그린 결과입니다. 코드는 복사 버튼으로 가져가서 직접 실행해 보세요.

1. client - server 구조

브라우저(Client)가 서버에 요청을 보내고, 서버는 필요하면 DB에서 데이터를 꺼내 HTML이나 JSON으로 응답합니다. 이 문서에서 다루는 HTML/CSS/JS는 전부 Client, 즉 브라우저 안에서 동작합니다.

2. client에서 html css js 역할

HTML은 구조(제목, 버튼이 있다), CSS는 모양(제목이 빨갛다), JS는 동작(버튼을 누르면 숫자가 오른다)을 맡습니다. 오른쪽 결과에서 +1 버튼을 눌러 보세요.

3. react 역할 : html - react 간단한 비교

같은 카운터를 React로 쓰면 이렇게 됩니다. HTML 버전은 "화면에서 요소를 찾아서 직접 고치는" 방식이고, React는 "상태(count)가 바뀌면 화면은 알아서 다시 그려지는" 방식입니다. 실행 결과는 React 라이브러리를 인터넷에서 불러와 동작하므로 온라인 상태여야 보입니다.

4. html 기본 태그

4-1 HTML 기본 태그 정리

4-1-1 웹 문서 기본

<!DOCTYPE html>문서가 HTML5임을 선언
<html>HTML 문서의 루트 요소
<head>문서의 메타데이터를 포함하는 영역
<body>실제 화면에 표시되는 콘텐츠 영역

4-1-2 문서 정보

<title>문서 제목, 브라우저 탭에 표시
<meta>문자 인코딩, 설명, 키워드 등 메타데이터 설정
<link>외부 CSS, 아이콘 등 리소스 연결
<script>자바스크립트 코드 삽입 또는 외부 스크립트 연결

4-1-3 문서 구조

<header>페이지 또는 섹션의 머리글
<nav>내비게이션 링크 모음
<main>문서의 주요 콘텐츠 영역
<section>주제별 콘텐츠 구역
<article>독립적으로 구분되는 콘텐츠 블록
<aside>부가 정보나 보조 콘텐츠
<footer>페이지 또는 섹션의 바닥글
<div>비시맨틱 블록 컨테이너
<span>인라인 컨테이너

4-1-4 텍스트

<h1> ~ <h6>제목 계층 구조 표시
<p>문단
<strong>중요한 강조 텍스트
<em>기울임 강조 텍스트
<mark>하이라이트 표시
<small>부가 설명, 작은 텍스트
<abbr>약어와 전체 의미 제공
<code>코드 조각 표시
<pre>공백과 줄바꿈을 유지하는 코드/텍스트
<blockquote>인용문 표시
<a>하이퍼링크 생성

4-1-5 목록

<ul>순서 없는 목록
<ol>순서 있는 목록
<li>목록 항목
<dl>설명 목록
<dt>설명 목록의 용어
<dd>설명 목록의 설명

4-1-6 표

<table>표 전체를 감싸는 요소
<caption>표의 제목
<thead>표의 헤더 영역
<tbody>표의 본문 영역
<tfoot>표의 바닥글 영역
<tr>표의 행
<th>표의 헤더 셀
<td>표의 데이터 셀

4-1-7 멀티미디어

<img>이미지 삽입
<audio>오디오 삽입
<video>비디오 삽입
<track>비디오/오디오의 자막·메타데이터 트랙
<picture>반응형 이미지 제공
<source>미디어 소스 파일 지정

5. form 태그

HTML form 태그 정리

5-1-1 form 핵심 태그

<form>입력 데이터를 감싸고 제출 동작을 정의하는 컨테이너
<label>입력 요소와 연결되는 레이블(접근성·클릭 영역 확대)
<input>단일 행 입력 필드(다양한 type 지원)
<textarea>여러 줄 텍스트 입력
<button>버튼(제출·초기화·일반)
<fieldset>관련 입력들을 그룹화
<legend>fieldset 그룹의 제목

5-1-2 선택/목록 입력

<select>드롭다운 선택 상자
<option>select 안의 선택 항목
<optgroup>option들을 논리적으로 묶는 그룹
<datalist>input과 함께 자동완성 후보 목록 제공

5-1-3 상태/결과 표시

<output>계산 결과 등 동적 출력 값 표시
<progress>작업 진행률(0~1 또는 값/최대값) 표시
<meter>측정값(예: 점수·용량)의 상대 범위 표시

5-1-4 input 타입

type="text"일반 텍스트 입력
type="password"비밀번호 입력(가려짐)
type="email"이메일 형식 검증/가상 키보드 최적화
type="url"URL 형식 검증
type="number"숫자 입력(min/max/step 지원)
type="tel"전화번호 입력(모바일 키패드 최적화)
type="search"검색 입력
type="date"날짜 선택기
type="time"시간 선택기
type="datetime-local"로컬 날짜·시간 선택
type="month"월 선택
type="week"주 선택
type="color"색상 선택
type="checkbox"다중 선택 체크박스
type="radio"단일 선택 라디오 버튼(그룹은 name으로)
type="range"슬라이더(범위 값)
type="file"파일 업로드
type="hidden"화면에 보이지 않는 값
type="submit"폼 제출
type="reset"폼 초기화
type="button"일반 버튼(스크립트와 함께 사용)

5-1-5 주요 속성

action폼 제출 URL
methodHTTP 메서드(get/post 등)
enctype폼 데이터 인코딩 타입(파일 업로드 시 multipart/form-data)
name폼/입력 요소의 이름(서버 전송 키)
id/forlabel과 입력 요소 연결
value입력 요소의 현재 값/기본값
placeholder힌트 텍스트
required필수 입력
readonly읽기 전용
disabled비활성화
min/max/step수치·날짜 범위/간격
pattern정규식 패턴 검증
multiple다중 선택/다중 파일 업로드 허용
accept파일 업로드 허용 형식
autocomplete자동완성 동작 설정(on/off 또는 힌트)
